# sdr-app

Desktop SDR-приёмник на C++20 и Qt Quick. Текущая реализация v0.1 — предварительная сборка: полная аппаратная и длительная приёмка ещё не завершена.

Реализованы локальные источники через SoapySDR, файловый и синтетический IQ, AM/NFM/WFM, спектр/waterfall, аудиовывод, WAV/Raw IQ, настройки и нативные Source/Demodulator плагины. Проверенная аппаратура и ограничения перечисляются в отчёте, а не выводятся из одного успешного запуска.

Собственный код — MIT. Qt, SoapySDR и установленные отдельно драйверы имеют свои условия распространения. Приложение не передаёт телеметрию автоматически. TX, удалённые источники и недоверенные плагины не входят в v0.1.
