# Proposal

## Why
Защищённый прогон остановился через 757 s с IQ overflow: max worker gap 405 ms при DSP 14.6 ms и записи 9.7 ms. В Engine найден таймерный опрос пустой очереди с sleep(1 ms). Его избыточные пробуждения воспроизводимы; связь с конкретной длинной паузой ещё не доказана.

## What Changes
Ожидать данные/команды/завершение источника по уведомлению вместо polling sleep. Сохранить bounded queues, overflow/stop и прежние параметры. Дополнить maxima спектром, audio push и полным блоком.

## Capabilities
### New Capabilities
Нет.
### Modified Capabilities
Нет: skip_specs=true, внутренний механизм ожидания без смены внешнего контракта.

## Impact
Engine, регрессионные тесты и телеметрия. Решение — ADR-019. Не объявлять исправленной первопричину всех системных stalls или пройденным endurance по короткому прогону.
