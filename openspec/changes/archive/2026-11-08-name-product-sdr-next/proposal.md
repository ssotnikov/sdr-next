# Proposal

## Why
Пользователь утвердил название программы `SDR Next`.

## What Changes
Название фиксируется в документации, display name приложения и заголовках обычного и тестового окна. Технические имена проекта, executable, ABI и каталогов настроек сохраняются для совместимости.

## Capabilities
### New Capabilities
- `product-identity`: отображаемое имя программы.
### Modified Capabilities
Нет.

## Impact
README, руководство пользователя, Qt display name, заголовки и Windows launcher. Запущенный endurance-процесс не пересобирается и не перезапускается.
