# Proposal

## Why
Пользователь поручил начать восьмичасовой тест по ADR-015. Нужен реальный GUI/audio/recording прогон с сырыми метриками и сохранением непроверенных критериев.

## What Changes
- Добавляется opt-in длительный режим GUI: выбранный provider, 2.4 MSPS, WFM, WAV, JSONL и итоговый JSON.
- Собираются счётчики RX/audio, CPU, RAM, свежие отображённые спектры и задержки очереди GUI. Последние не заменяют измерение реакции на пользовательский ввод; физическая аудиозадержка остаётся непроверенной.
- Windows удерживается от автоматического сна только на время процесса. Исходные пользовательские настройки не меняются.

## Capabilities
### New Capabilities
- `rx-endurance`: воспроизводимый длительный прогон с честным частичным verdict.
### Modified Capabilities
Нет. Родительский MVP сохраняет полную приёмку, 10/20 MSPS и остальные среды.

## Impact
GUI opt-in harness, инструкция запуска и протокол в docs/sdr/. Пороговые значения ADR-015 не меняются. WAV около 2.8 GB; непрерывный Raw IQ не используется из-за объёма около 553 GB.
