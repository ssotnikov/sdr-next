# Spec Delta

## Purpose

Обеспечить воспроизводимую разработку desktop-приёмника на двух ОС и проверку вычислительного ядра независимо от интерфейса.

## ADDED Requirements

### Requirement: Сборка desktop на двух платформах
Проект SHALL предоставлять документированную сборку приложения и автоматические проверки для Windows и Linux x86-64. Точные версии ОС и инструментов требуют утверждения O-001 до приёмки G0.

#### Scenario: Сборка из чистого окружения
- **WHEN** разработчик выполняет документированные шаги в каждом утверждённом окружении
- **THEN** создаются приложение и тестовые артефакты с указанными версиями инструментов и зависимостей

### Requirement: Независимая проверка ядра
Проект SHALL позволять собрать и проверить SDR/DSP-ядро без графического интерфейса и без зависимости его публичных контрактов от Qt.

#### Scenario: Проверка без GUI
- **WHEN** запускаются тесты ядра в окружении без Qt
- **THEN** вычислительные проверки выполняются без создания окна и загрузки Qt

### Requirement: Воспроизводимость зависимостей
Проект SHALL фиксировать версии инструментов, baseline пакетов и внешних SDK, достаточные для повторения сборки. Отсутствующие аппаратные драйверы SHALL быть явно указаны в инструкции.

#### Scenario: Отсутствует обязательная зависимость
- **WHEN** сборке или запуску требуется отсутствующая библиотека либо драйвер
- **THEN** разработчик получает диагностическое сообщение с названием зависимости вместо ложного сообщения об успешной готовности
