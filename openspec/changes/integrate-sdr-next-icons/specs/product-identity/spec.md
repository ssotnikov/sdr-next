# Spec Delta

## ADDED Requirements
### Requirement: Иконка приложения
Приложение SHALL использовать предоставленный набор assets/icon для иконки окна и панели задач. Windows executable SHALL содержать встроенную многоразмерную иконку. Поставка SHALL не требовать внешней папки исходных изображений для отображения иконки.
#### Scenario: Иконка Windows executable
- **WHEN** собрана Windows-версия с новым набором ресурсов
- **THEN** executable содержит иконку SDR Next с вариантами для разных размеров
#### Scenario: Иконка запущенного приложения
- **WHEN** запускается обычное или тестовое окно новой сборки
- **THEN** Qt использует предоставленную иконку независимо от текущей рабочей папки
