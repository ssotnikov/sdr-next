# Иконка SDR Next

Основание: пользователь предоставил `assets/icon/` и поручил использовать иконки при следующей сборке. SVG и PNG являются исходными пользовательскими материалами, их пиксели/векторные данные не изменяются.

Qt window icon составляется из встроенных PNG 16, 20, 24, 32, 40, 48, 64, 96, 128, 256 и 512 px. Все файлы входят в Qt resources executable; внешняя папка assets для запуска не требуется. SVG сохраняются как исходники, runtime-декодер SVG для иконки не добавляется.

Windows EXE содержит ICON resource из `assets/icon/sdrnext.ico`, упакованного из предоставленных PNG 16–256. Генерация — `python scripts/generate-icon-ico.py`, только стандартная библиотека, без перерисовки/ресайза. Python не является новой зависимостью сборки: ICO хранится как исходный ресурс. RC template получает абсолютный путь через CMake; включение RC ограничено Windows GUI target.

Иконка назначается через QGuiApplication до создания QML окон и применяется к обычному запуску и endurance. Технические имена executable, настроек и SDK не меняются. При следующей сборке требуется проверить compilation ресурсов и отображение в Explorer, заголовке/панели задач. Текущий длительный RX не пересобирается и не перезапускается ради этой проверки.
