# Реестр исходных открытых решений

## Текущий статус на 2026-11-07

Пользователь согласовал O-001: [ADR-013](ADR-013-desktop-platforms.md). Остальные технические решения делегированы агенту с фиксацией: [ADR-014](ADR-014-mvp-implementation-contracts.md). Они приняты в рамках делегации; реализация и испытания каждого решения отслеживаются отдельно.

O-011 (эталонный компьютер), O-012 (performance и минимальные DSP-критерии) согласованы пользователем в [ADR-015](ADR-015-reference-and-acceptance.md). O-006 (полная аппаратная матрица) остаётся открытым: HackRF One обнаружен и прошёл короткий Windows RX, RTL-SDR и Airspy не предоставлены. O-016…O-018 относятся к развитию после MVP и не согласованы. Для O-014/O-019 технический путь выбран, но платформенные/релизные проверки не завершены. Выбор решения и прохождение его приёмки учитываются отдельно в [отчёте](MVP_V0_1_VERIFICATION.md).

Пользователь явно перенёс реальные испытания RTL-SDR/Airspy после MVP: [ADR-016](ADR-016-deferred-device-qualification.md). Эта часть O-006 теперь deferred и сама по себе не блокирует v0.1; аппаратная приёмка HackRF и остальные gates сохраняются. Код адаптеров остаётся, подтверждённая совместимость отложенных моделей не заявляется.
