# Проверка адаптации brand book для Qt Quick

Дата: 2026-11-08. Изменение OpenSpec: adapt-brand-theme-qml. Решение: [ADR-020](ADR-020-qml-brand-theme.md).

## Результат
Цвета, шрифты и размеры перенесены в BrandTheme.qml/BrandTokens.js. Go/Gio код не добавлялся. Пять TTF и SIL OFL побайтно совпадают с предоставленным комплектом; hash-инвентарь: assets/fonts/README.md. Qt resources содержат шрифты приложения и QML-тестов. CMake install и Windows package script включают OFL.

MSVC 2026 (19.51.36260), Qt 6.10.0 msvc2022_64, Release, каталог build/windows-brand-msvc2026. Итоговый CTest: **7/7 passed**, 7.94 s. Отдельный подробный QML-лог: **8 passed, 0 failed, 1 skipped**. Пропущен физический HackRF, который занят длительным RX. Проверены FontLoader.Ready для всех пяти шрифтов, семейства Sans/Mono, размер 13/32, кнопка 28, ширина частоты и селекторов, тёмные/светлые цвета и ARGB-прозрачность, LUT Next, клавиатурный фокус, минимальное окно, синтетический RX и сохранение рабочей области. Сравнение контраста 18 пар на каждую тему не выявило нарушений порогов 4.5:1 для текста и 3:1 для проверенных границ/линии.

Нативная визуальная проверка Windows: обе темы в окне 1000×650, полная частота 100.000000, видимые значения темы/языка, прокрутка боковой панели; голубая/синяя линия и Next на синтетическом сигнале, иконка антенны в заголовке. Подсказка без RX перенесена в верхнюю область спектра, чтобы в светлой теме не попадать на тёмный waterfall. Финальный executable и проверочный экземпляр совпадают: SHA-256 23E82B5BE8CA50600DFA8F207775DFD245D7521F76BFF09FCB87D374BC9E0B1F. Проверочное окно: build/brand-preview/sdr_app.exe, отдельные portable-настройки, RX остановлен.

## Найденные и исправленные проблемы проверки
- Пользовательские backgrounds убрали стандартную implicitWidth селекторов: значения темы/языка сжимались до стрелки. Заданы ширины и добавлена проверка размещения текста.
- Временный deployment непосредственно в bin тестовой сборки создал qt.conf с локальными plugins без offscreen и portable.txt. Это вызвало ошибку Qt у sdr_ui_tests и конфликт настроек settings-test. Комплект вынесен в build/brand-preview; конфигурация preview в bin отключена переименованием, исходники настроек пользователя не менялись. CTest теперь задаёт путь платформенного плагина через Qt6::QOffscreenIntegrationPlugin. Повторные итоговые проверки прошли.
- Проверка msvc-dependencies требует Developer PowerShell: отдельный запуск вне него закономерно не нашёл include dependencies. Итоговый CTest выполнен с окружением VS 2026.
- Offscreen Qt сообщает об отсутствии системного каталога lib/fonts; пять встроенных FontLoader успешно загружены, нативное окно отображает кириллицу. Это не ошибка загрузки встроенных шрифтов.

## Границы результата
Linux, физическая аппаратная приёмка, полная HiDPI-матрица и восьмичасовые критерии этим изменением не подтверждены. Работающая аппаратная сборка и её процесс 2096 не заменялись; дополнительная нагрузка сборки отмечена в [протоколе текущего прогона](RX_ENDURANCE_CABLE_RETRY_2026-11-08.md). Предыдущие провалы не превращаются в pass.

Исходный private/brand-book не публикуется целиком. По текущему пользовательскому .gitignore новые OpenSpec-файлы остаются локальными; правило игнорирования не менялось. Локальная спецификация и архив изменения сохраняются в openspec/.

## Сопоставление со спецификацией

| Требование | Реализация и свидетельство |
|---|---|
| Темы интерфейса | BrandTheme.qml и привязки Main.qml; test_brand_theme, test_receiver_and_workspace; нативное переключение dark/light без перезапуска |
| Встроенные шрифты и размеры | FontLoader, ресурсы обоих executable, text/metrics из предоставленных JSON; test_brand_theme и test_brand_minimum_window |
| Палитра Next | Сплошной LUT из семи stops, colorMap=2; тест крайних и промежуточного цветов; индексы Ocean=0/Amber=1 не менялись |
| Состояния элементов | Общие backgrounds, hover/down, disabled opacity, focus ring, семантические статусы; проверка visualFocus в QML и нативный RX |

Сохранённые акценты и выбор палитры не сбрасываются. Если акцент ещё не сохранялся, используется янтарный; старое сохранённое значение невозможно надёжно отличить от явного выбора пользователя. Непрерывное системное масштабирование следует Qt; отдельная полная матрица DPI остаётся за пределами этой проверки.
