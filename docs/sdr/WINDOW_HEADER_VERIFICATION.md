# Проверка фирменного заголовка SDR Next

Дата: 2026-11-08. OpenSpec: add-branded-window-header. Решение: [ADR-021](ADR-021-branded-window-header.md).

## Реализованное оформление
Единая полоса 44 логических пикселя с burger 34×34, отступом 12 и кнопками окна 46×44. По последнему уточнению пользователя значок после burger исключён. Надпись набрана IBM Plex Sans SemiBold 16, интервал между SDR и Next — 4. SDR: ink (#E6EBF0 dark / #0E141A light), Next: dialInk (#FFB224 dark / #8A4B00 light). Светлая тема использует контрастный текстовый янтарный токен. Иконка executable/панели задач не менялась. Промежуточные SVG-ресурсы заголовка удалены, QtSvg не добавляется как новая явная зависимость.

Главное меню содержит существующие действия файлов, приёма, вида и справки. F10/Alt+M открывают меню; Escape закрывает его, Space/Escape RX заблокированы при открытом popup. В endurance burger, shortcut и изменяющие RX команды недоступны. Меню и надпись поддерживают RU/EN и обе темы.

## Автоматические проверки
MSVC 2026, Qt 6.10.0, Release, build/windows-brand-msvc2026. Итоговый CTest: **8/8 passed**, 7.78 s.

Подробный QML-прогон: 10 passed, 0 failed, 1 skipped (физический HackRF). Проверены два текста и два цвета в обеих темах, отсутствие titleLogo, размеры заголовка и кнопок, drag-region, maximize/restore, обе темы и minimum window, F10/Escape при синтетическом RX без его остановки, перестановка панели и endurance guards. Отдельный window-chrome тест проверяет все восемь границ/углов, дробные координаты, внутренние/внешние точки и запрет resize в отключённом состоянии.

## Нативная проверка — остаётся открытой
До последнего уточнения визуально проверены тёмный заголовок с прежним SVG, burger и popup, Escape, maximize/restore (1000×650 ↔ 1536×816) и закрытие preview. Drag через Qt/QML дважды не изменил положение (335,104); это наблюдение, а не подтверждённая причина. После этого добавлен Windows hit-test адаптер WM_NCHITTEST. Перетаскивание, resize, двойной щелчок и minimize после адаптера не подтверждены.

При запуске обновлённого preview Computer Use сообщил об остановке пользователем физическим Escape. Дальнейшие GUI-действия прекращены. Последняя двухцветная надпись проверена автоматическими тестами; её повторная визуальная проверка и полный набор системных жестов остаются задачей 3.2 OpenSpec. Изменение не архивировано, аппаратные gates не закрыты.

Windows адаптер ограничен основным окном и использует ScreenToClient/devicePixelRatio; Linux сохраняет Qt system move/resize. Linux compositor, Snap flyout и полная матрица DPI остаются not_verified. Справочные первоисточники: [Qt QWindow](https://doc.qt.io/qt-6/qwindow.html#startSystemMove), [Qt 6.10 Windows platform implementation](https://github.com/qt/qtbase/blob/v6.10.0/src/plugins/platforms/windows/qwindowswindow.cpp).

## Размещение
Новая сборка для ручного запуска: build/two-tone-header-preview/sdr_app.exe. Она подготовлена отдельно от старых preview и работающего endurance, автоматически не запускалась после остановки GUI-проверки. Проверки не заменяют бинарник процесса RX 2096. Нагрузка сборки и synthetic-проверок добавляется к уже отмеченному изменению условий длительного прогона. Исходники BareMark не копировались и не изменялись. Новые OpenSpec-артефакты остаются локальными по пользовательскому правилу /openspec/ в .gitignore.
