# ADR-020 — Адаптация brand book для Qt Quick

Дата: 2026-11-08. Статус: принято в рамках делегации технических решений, по поручению пользователя адаптировать цвета, шрифты и размеры.

## Контекст
Предоставленный комплект содержит темы JSON, Go/Gio адаптер и IBM Plex с SIL OFL. Стек Qt Quick/C++20 утверждён ранее. Полный private-каталог не становится частью поставки.

## Решение
Перенести семантические цвета, типографику и метрики в BrandTheme.qml/BrandTokens.js. Явно преобразовать RGBA в Qt ARGB. Пять неизменённых файлов IBM Plex встроить в resources вместе с приложением и QML-тестами; лицензию поставлять в licenses/IBM-Plex. Дополнительных GUI-библиотек не вводить.

Логические пиксели Qt соответствуют dp/sp исходного адаптера при базовом масштабе; масштабирование ОС сохраняется. FontLoader возвращает фактические имена семейств каждого веса. Частотное поле имеет размер 32 и достаточную ширину для полного значения. Боковая панель по умолчанию 288, ранее сохранённая ширина остаётся.

Янтарный акцент становится стандартным. Все сохранённые акценты сохраняются, включая прежний бирюзовый: старый default невозможно отличить от явного выбора пользователя. Янтарный используется при отсутствии сохранённого значения. Индексы Ocean=0 и Amber=1 сохраняются, Next=2 выбран при отсутствии сохранённого значения. Цвет линии спектра следует теме; карта Next одинакова для обеих тем.

## Альтернативы и последствия
Копирование Go/Gio изменило бы согласованный стек. Системные шрифты не обеспечивают одинаковую типографику. Встроенные ресурсы увеличивают размер executable, но устраняют необходимость установки шрифтов. Новый контракт загрузки внешних тем не вводится.

## Проверка
OpenSpec adapt-brand-theme-qml отслеживает загрузку ресурсов, переключение тем, синтетический RX и визуальную проверку. Полная приёмка MVP и открытые вопросы не закрываются этим изменением.
