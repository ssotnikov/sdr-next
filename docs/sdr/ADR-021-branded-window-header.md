# ADR-021 — Фирменный заголовок и главное меню

Дата: 2026-11-08. Статус: принято по поручению пользователя реализовать логотип и burger как в BareMark; технические детали — в рамках делегации.

## Решение
Qt Quick frameless окно получает верхнюю полосу 44 логических пикселя, burger 34×34 (три линии 14×1 с шагом 5), логотип через 12 пикселей, кнопки окна 46×44. Эти параметры и композиция проверены по текущему BareMark; Go/Win32 исходники не копируются. Применяются собственные цвета SDR Next.

Уточнение пользователя: значок антенны после burger убран. Надпись SDR Next рисуется встроенным IBM Plex Sans SemiBold 16: SDR — ink (#E6EBF0 dark / #0E141A light), Next — dialInk (#FFB224 dark / #8A4B00 light). Используется контрастный текстовый янтарный токен светлой темы. Иконка executable/панели задач сохраняется. Дополнительная SVG-зависимость для заголовка не нужна.

WindowTitleBar и WindowResizeHandles используют Qt startSystemMove/startSystemResize и операции QWindow. Меню Qt Quick Popup.Item вызывает существующие действия; языки RU/EN и оформление наследуются от окна. Системное имя/title, portable-настройки и аппаратные API сохраняются. При endurance burger и соответствующие shortcuts недоступны, изменяемое название теста выводится в заголовке.

## Последствия и проверка
Нативная рамка не дублируется, но платформенные жесты требуют самостоятельной проверки. Windows drag/resize/maximize/restore/minimize/close, обе темы, keyboard-menu и guards проверяются OpenSpec add-branded-window-header. Linux compositor, Snap flyout и полная DPI-матрица не считаются подтверждёнными только по Windows/QML тестам. Открытые аппаратные решения и длительный RX не закрываются этим изменением.

## Уточнение обработки Windows
Нативный тестовый drag не изменил положение окна при передаче операции через QML startSystemMove. Для Windows вводится узкий QAbstractNativeEventFilter только основного окна: WM_NCHITTEST возвращает HTCAPTION в свободной области заголовка и стандартные resize-коды на границе. Координаты ScreenToClient переводятся в логические пиксели по devicePixelRatio; зоны интерактивных кнопок и логотипа не становятся caption. Применяются публичные Qt и Win32 API, без сторонних библиотек и private Qt headers. Qt startSystemMove/startSystemResize остаются fallback для остальных платформ. Геометрия границ проверяется отдельным тестом, полный путь — нативными жестами.
