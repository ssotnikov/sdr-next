# ADR-014 — Контракты реализации MVP v0.1

Дата: 2026-11-07. Статус: **технические решения приняты по явной делегации пользователя**: «Делегирую тебе технические решения с фиксацией в ADR». Решения об аппаратной приёмке и количественных SLO не входят в делегацию.

## Решения и границы

| Вопрос | Решение |
|---|---|
| O-002 | SoapySDR 0.8.x для локальных RTL-SDR/HackRF/Airspy. Драйверы — отдельно установленные пользователем модули; SoapyRemote не перечисляется и не используется. В сборке без SDK аппаратный RX явно недоступен. |
| O-003 | Внутренний CF32, блок до 16384 complex<float>. Неизменяемый блок передаётся через shared ownership в bounded queue ёмкостью 8. Source→DSP не ждёт GUI. Индексы относительно начала сеанса, sequence и discontinuity. Если место не освободилось за ограниченное ожидание 20 ms, RX останавливается с overflow. |
| O-004 | Собственные оконные FIR-фильтры и radix-2 FFT 2048/Hann на CPU; без liquid-dsp, FFTW и GPU DSP. SIMD и дополнительные backends не обязательны v0.1. Автовекторизация компилятора допустима. |
| O-005 | Qt Multimedia QAudioSink, mono float32/48 kHz, ограниченный аудиобуфер 250 ms с начальным заполнением 100 ms. Фактический буфер устройства сообщается Qt. Устройство без этого формата отклоняется, ошибки и недостаток данных диагностируются. |
| O-007 | Одно окно, две области SplitView с регулируемой шириной, панель управления слева/справа, вкладки RX/Audio/Files. Раскладка сохраняется. Отдельные плавающие окна и произвольное вложение не входят v0.1. |
| O-008 | Raw IQ — чередующиеся IEEE754 float32 I/Q little-endian, файл .cf32 и sidecar .cf32.json v1. Частота/rate/capture point/UTC/число samples/gaps/complete описываются явно. Metadata атомарно записывается сначала incomplete, после штатного закрытия complete. Смена конфигурации во время записи отклоняется. Повреждённые/незавершённые записи не выдаются за непрерывные и требуют отдельного восстановления. WAV PCM16 mono/48 kHz с пределом RIFF 4 GiB. |
| O-009 | C ABI v1.0 в sdk/include/sdr/plugin.h. Две категории; фиксированные POD-типы, struct_size/major/minor. Host выделяет вход/выход, они borrowed только на время вызова. Плагин сам создаёт/освобождает свой opaque instance. Синхронные вызовы одного instance выполняются в одном worker, фоновые потоки/host callbacks в v0.1 не поддерживаются. Весь исходный IQ и offset передаются demodulator; встроенный DSP владеет своим DDC/ресемплингом, плагин — своим. |
| O-010 | Instance держит shared ownership библиотеки до destroy; перед отключением активного source/demodulator нужен stop RX. Ошибка init откатывает загрузку, библиотека не выгружается при живом instance. Нарушения ABI нативным доверенным кодом не изолируются. |
| O-013 | Спектр рисуется QSGGeometry, waterfall — texture node с ограниченной историей 256 строк. Штатный Qt Quick RHI backend; software backend доступен для проверки, поддержка конкретной GPU объявляется только после испытаний. |
| O-014 | Целевые X11 и Wayland, Qt HiDPI; USB permissions/udev документируются как prerequisites. Это решение объёма, а не отметка прохождения платформенной матрицы. |
| O-015 | RU/EN в v0.1, переключение языка GUI без изменения DSP. Встроенные пары переводов; языковые пакеты позже. |
| O-019 | Портативная папка Windows и tar.gz Linux. Qt динамический, SDK-примеры отдельно. Устройства требуют внешних драйверов. Для Linux со старшей glibc — сборка на Ubuntu 22.04 из исходников; универсальность пакета не предполагается без проверки. |
| O-020 | Локальные JSONL события, ограниченные 4 MiB; счётчики IQ gaps/queue overflow/audio starvation. Никакой автоматической телеметрии, crash upload или сетевого отчёта. Экспорт локального журнала — действие пользователя. Автоматические minidumps не реализуются. |

Один VFO в v0.1 принят как техническое ограничение в рамках делегации. AM/NFM/WFM — mono; WFM со стандартной 75 μs deemphasis, стерео/RDS не заявлены. Все режимы имеют частотный перенос, канальный FIR, ограничение аудиополосы, AM DC removal и базовую нормализацию; это не заявление о достигнутых DSP-допусках.

Численные ёмкости буферов и длины фильтров — параметры реализации, не утверждённые пороги приёмки O-012. После реального HackRF GUI-теста начальное заполнение аудиобуфера увеличено до 100 ms (или размера первого запроса, если он больше), запрошенный буфер QAudioSink уменьшен до 50 ms. Это устраняет стартовое чтение большого блока из ещё недостаточно заполненной очереди; суммарную задержку проверяют отдельно по ADR-015. Счётчик включает starvation собственного буфера и UnderrunError backend, сохраняется после stop и обнуляется только новым RX. DSP worker не спит между готовыми IQ-блоками; искусственная пауза после каждого блока удалена после выявления падения темпа обработки на Windows.

## Не закрыто этим ADR

Аудиоадаптер QIODevice открыт в режиме Unbuffered: предварительное чтение внутреннего QIODevice-буфера поверх нашего ring вызывало лишние крупные запросы и перемежающиеся startup underrun. После отключения этого дополнительного буфера три последовательных коротких HackRF/QML прогона дали нулевые IQ gaps/overflow/audio drops/underrun. Это свидетельство устранения наблюдавшегося дефекта, не прохождение восьмичасовой приёмки.

O-006: RTL-SDR/Airspy и полная аппаратная матрица не подтверждены. HackRF One был обнаружен после подключения пользователем. O-011/O-012 позднее согласованы отдельно в ADR-015; этот технический ADR их не утверждает. O-016…O-018 остаются после MVP. Лицензионная приёмка фактической поставки и проверки платформ выполняются отдельно.

## Альтернативы

Уточнение 2026-11-07 после реального HackRF GUI-теста: драйвер выдаёт серии по восемь блоков 16384 samples после ожидания около 50 ms (внутри серии чтение 50–180 μs). Мгновенный отказ на заполненной очереди приводил к ложному stop при краткой задержке DSP. Очередь остаётся ёмкостью 8; acquisition worker может ожидать свободное место до 20 ms с прерыванием по stop token. Если DSP не освободил место за это время, RX останавливается с overflow. USB callback драйвера этим ожиданием не блокируется, GUI не участвует. Это ограниченный backpressure, не расширение очереди и не скрытая потеря данных. Тесты покрывают timeout/освобождение/stop; реальный HackRF проверяется повторно. SLO latency требует отдельного измерения.

liquid-dsp/FFTW требуют дополнительных зависимостей и проверки вариантов сборки; собственная узкая реализация позволяет тестировать тракт независимо. Прямые аппаратные SDK дублируют драйверную абстракцию; оставлены за текущим объёмом. IPC/sandbox нужен для изоляции, но отложен ADR-003. Динамическая выгрузка во время RX заменена явным stop, что делает lifetime проверяемым без глобального прерывания чужого кода.
