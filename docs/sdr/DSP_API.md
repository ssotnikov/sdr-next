# Контракты SDR/DSP v0.1

Статус: реализация ADR-014. Публичный Plugin ABI отделён от C++ API ядра. Заголовки ядра не зависят от Qt.

## Данные

`Config` хранит источник rate/center, смещение VFO, режим, gain/ppm/bias/direct sampling и squelch. Значения проверяются до открытия тракта; аппаратный rate/center перечитываются после применения. Все численные частоты — Hz.

`Block`: CF32 samples, sample_index относительно начала сеанса, sequence, discontinuity. Максимум 16384 samples. `Source::read` возвращает false на EOF, пустой блок на timeout, исключение на неисправимую ошибку. Hardware timeout одной операции — 100 ms; отсутствие IQ 5 секунд останавливает RX. Soapy overflow помечает следующий пригодный блок как discontinuity. Количество потерянных аппаратных отсчётов не выдумывается, если драйвер его не сообщил.

Acquisition worker создаёт/читает/закрывает источник. Блок передаётся неизменяемым shared_ptr через очередь глубиной 8; full — явный stop/error. DSP/запись выполняются отдельным worker, GUI получает только последний spectrum snapshot. Дисковая задержка не блокирует аппаратный callback напрямую, но при систематическом отставании приводит к диагностируемому overflow. Гарантии sustained throughput определяются измерением.

Перед объявлением overflow acquisition worker допускает ограниченное ожидание свободного места до 20 ms, прерываемое stop. Это нужно для пакетной выдачи SoapyHackRF: несколько IQ-блоков поступают за микросекунды после ожидания аппаратного пакета. Очередь и latency не становятся неограниченными; GUI не находится в этом пути. Синтетический/file источник после задержки планировщика продолжает реальный темп без залпа «догоняющих» блоков.

## Демодуляция

`Demodulator::configure` задаёт NCO, оконный FIR и децимацию. `process` обрабатывает произвольные границы блоков с сохранением состояния и возвращает mono float32/48 kHz. Настройка/сброс выполняется в DSP worker, без одновременного вызова process. AM использует envelope/DC removal/нормализацию; FM — фазовую разность с ограничением аудиополосы; WFM — 75 μs deemphasis. WFM требует входной rate ≥192 kSPS. Частотный offset обязан быть строго внутри Nyquist.

При discontinuity встроенный demodulator сбрасывается. Плагин демодуляции получает ошибку/остановку для явного пересоздания, поскольку v1.0 не содержит reset callback. При изменении source rate или режима используется stop/recreate; старые callbacks не обслуживают новую конфигурацию.

Буферы аудио переиспользуются вызывающим кодом, однако source block allocation, выходные векторы и spectrum не объявляются allocation-free realtime. Оптимизация через pool/SIMD допустима после измерений без изменения внешней семантики.

## Спектр

Radix-2 FFT 2048, Hann, частотный порядок от −Fs/2 до +Fs/2, нормировка мощности по сумме окна. Полномасштабный комплексный тон имеет 0 dBFS в соответствующем bin. Без калибровки dBm не публикуется. Новые кадры формируются не чаще 20 Hz; GUI может пропускать устаревшие snapshots. Waterfall хранит 256 строк; при пропуске кадров его вертикальная ось не считается равномерной временной шкалой.

## Запись и ошибки

WAV writer формирует PCM16 little-endian mono/48 kHz и завершает RIFF header при close. Raw writer пишет CF32 little-endian; JSON sidecar атомарно ведётся приложением. Ошибка диска оставляет incomplete metadata и видимое сообщение. Конфигурация при активной записи неизменна. GUI не вызывается из DSP/source worker.

Ошибки C++ не пересекают C ABI. Контролируемая ошибка команды не разрушает работающий сеанс; ошибка acquisition/DSP останавливает тракт и фиксирует Faulted. Команды GUI ограничены очередью 32; при переполнении пользователь получает отказ вместо скрытого накопления.
