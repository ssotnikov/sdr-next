# ADR-018 — Название программы SDR Next

Дата: 2026-11-08. Статус: **принято пользователем**: «Зафиксируй название программы `SDR Next`».

## Решение
Отображаемое название продукта — **SDR Next**. Оно используется в пользовательской документации, Qt applicationDisplayName и заголовках окон, включая длительный тест.

Техническое имя репозитория/папки `sdr-app`, CMake target и executable `sdr_app`, существующие organizationName/applicationName `sdr-app`, пути настроек и ABI ID не меняются. Изменение display name не переносит и не сбрасывает настройки. Исходная архитектурная baseline остаётся неизменной.

## Проверка
Изменение исходников выполнено отдельно от работающего восьмичасового прогона. Сборка и runtime-подтверждение нового имени откладываются до его завершения; работающий бинарник продолжает использовать прежний заголовок. Владелец: OpenSpec `name-product-sdr-next`.
