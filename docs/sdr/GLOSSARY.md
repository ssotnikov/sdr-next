# Термины подключения источников SDR

| Термин | Значение в проекте |
|---|---|
| Драйвер SoapySDR | Внешний подключаемый модуль SoapySDR для семейства устройств. Не является собственным Source-плагином приложения. |
| Device Provider | Динамический модуль приложения по единому C ABI: перечисляет экземпляры устройств, сообщает возможности, применяет настройки, возвращает actual параметры и IQ. Каждый аппаратный provider устанавливается независимо. |
| Адаптер SoapySDR | Приватная реализация внутри отдельных Device Provider модулей HackRF/RTL-SDR/Airspy. Обращается к C API внешнего SoapySDR; core и GUI не знают семейств. |
| Source-плагин приложения | Отдельная доверенная DLL/SO, загружаемая по manifest через собственный C ABI SDK. Возвращает IQ; v1.0 не предоставляет полный API аппаратных возможностей и управления. |
| Аппаратная квалификация | Реальные проверки конкретной комбинации устройства, драйвера, ОС и скорости. Наличие адаптера или драйвера не означает успешной квалификации. |
| Отложенные испытания | Проверки перенесены на последующий этап явным решением пользователя. Это отдельный статус от pass и от обязательных незавершённых проверок текущего MVP. |
