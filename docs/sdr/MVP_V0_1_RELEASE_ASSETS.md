# Локальные артефакты кандидата SDR Next 0.1

Windows-кандидат собирается с `-WithoutOptionalWindowsBinaries` и отдельным получением Microsoft Visual C++ v14 x64 Runtime. Он использует динамические библиотеки Qt и штатный графический стек Windows. Для D3D11, WARP и программного backend Qt Quick действуют результаты испытаний ниже. Явный выбор Mesa software OpenGL требует дополнительной DLL, исключённой из кандидата. Итоговое решение о публичной поставке принимается после проверок 7.5–7.7 и [финальной приёмки 8.1](../../openspec/changes/plan-mvp-v0-1/tasks.md#8-g7--финальная-проверка-на-чистых-windows). [Microsoft Visual C++ Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist) · [Графические режимы Qt](https://doc.qt.io/qt-6.10/windows-graphics.html)

## Проверка выдачи исходников

Файлы скачаны полностью по HTTP с временного локального сервера на loopback. SHA-256 полученных данных совпали с таблицей. Для публичного выпуска разместить бинарный архив, соответствующие исходники и контрольные суммы рядом, указать способ замены библиотек и дать ссылку на исходники приложения из точной ревизии выпуска. После размещения повторить скачивание по фактическим ссылкам без авторизации и сравнить SHA-256. Проверка опубликованных ссылок и пересборка Windows Qt из исходного архива остаются открытыми. [Обязательства при использовании Qt по LGPL](https://www.qt.io/development/open-source-lgpl-obligations)

## Сборка и проверка Windows

Windows-бинарники собраны из ревизии `19a66ada6dab4dfec2f57a1f8f12190f1182a7ec` с Qt 6.10.0, MSVC 19.51.36260.0 и заголовками SoapySDR из закреплённого SDK. CTest прошёл 8/8. MSVC 2026 входит в матрицу по уточнению [ADR-013](ADR-013-desktop-platforms.md) от 2026-11-11.

После распаковки ZIP в путь с пробелами сверены размеры и SHA-256 всех 1 496 файлов манифеста. Все 86 Qt DLL совпали с инвентарём архива исходников. В пакете 54 записи Qt SPDX и 67 текстов лицензий и уведомлений. В комплекте три модуля устройств. Пять исключённых файлов отсутствуют.

На эталонной Windows 11 build 26300 синтетический RX завершился успешно во всех трёх запусках с системным `PATH`. Журналы подтвердили D3D11 на AMD Radeon, D3D11 WARP на Microsoft Basic Render Driver и программный backend Qt Quick. Проверка использовала уже установленный VC++ Runtime. Отдельных чистых сред Windows 10 и 11 для проверки установки runtime и первого запуска не было. Журналы в `build/endurance/windows-candidate-*.log`.

Параметры штатного упаковщика для кандидата. Пути к исходникам и Tika NOTICE заданы в [инструкции по атрибуции Windows Qt](QT_WINDOWS_SOURCE_PROVENANCE.md#уведомления-для-windows-пакета).

```powershell
.\scripts\package-windows.ps1 -QtRoot $qtSdk -BuildDirectory $buildDir -OutputDirectory $candidateDir `
    -WithoutOptionalWindowsBinaries -QtNoticeSource $verifiedQtSource -TikaNotice $tikaNotice
```

В финальной задаче 8.1 после завершения разработки на чистых Windows 10 22H2 x64 и Windows 11 x64 проверить установку VC++ Runtime из официального источника, запуск через `Start-SDR.cmd` и синтетический RX с системным `PATH`. Проверить звук и обновление спектра, D3D11 и WARP, затем задокументировать версии ОС, runtime, драйвера и выбранный Qt backend. Физические проверки HackRF учитываются отдельно по протоколу приёмки.

## Функциональная проверка распакованного Windows-кандидата

В отдельной копии пакета на эталонной Windows 11 build 26300 через GUI запущен синтетический WFM RX на 2,4 MSPS и выполнена одновременная запись WAV и Raw IQ. Спектр и waterfall обновлялись. После штатной остановки CF32 содержал 24 444 928 комплексных отсчётов. Размер 195 559 424 байта соответствует sidecar. В sidecar указаны `complete: true` и пустой список разрывов. WAV содержит 488 898 кадров PCM16 mono 48 кГц. На секундном отрезке после старта по пересечениям нуля подтверждён тон 1 кГц. Слышимый вывод и физическая задержка в этом прогоне отдельно не измерялись.

Тот же CF32 открыт через диалог приложения и воспроизведён до EOF. Окно вернулось в Ready, счётчики IQ gaps и audio underrun показали ноль. Поставляемые примеры Source и Demodulator добавлены через их manifest JSON, выбраны в GUI и вместе запустили RX с обновлением спектра и waterfall. Английский язык и файловый источник восстановились из соседнего `sdr-settings.json` при повторном запуске.

Записи и настройки находятся в тестовой копии под `build/endurance/`. SHA-256 исходного ZIP повторно совпал с таблицей. Чистые Windows 10/11, установка VC++ Runtime с нуля и аппаратные сценарии остаются отдельными проверками.
