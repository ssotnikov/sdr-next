# ADR-025. Диагностика чтения IQ

Статус — принято в рамках делегированных технических решений MVP.

Прикладная трасса RX разделяет вызов драйвера и проверку с преобразованием IQ в хосте. Это позволяет локализовать паузу чтения без системной трассы Windows. Измерения по монотонным часам включают время вне исполнения потока. Для различения задержки планирования и ожидания драйвера нужна системная трасса.

Device Provider может экспортировать `sdr_device_read_diagnostics_v1` с теми же правилами чтения и дополнительным выходом для времени и кода драйвера. Хост использует его только при включённой диагностике. При отсутствии символа хост вызывает обычный `read` и измеряет преобразование.
