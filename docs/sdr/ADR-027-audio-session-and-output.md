# ADR-027. Аудиосеанс и выбор выхода

Статус — принято в рамках делегированных технических решений MVP.

Очередь воспроизведения имеет поколение сеанса. Остановка или запуск RX инвалидируют предыдущий аудиовход. Старый `QIODevice` при позднем чтении получает тишину и не меняет счётчики нового сеанса. При переходе на новый сеанс контроллер сбрасывает буфер прежнего `QAudioSink` и создаёт новый. Правила накопления и коррекции темпа остаются описаны в [ADR-024](ADR-024-playback-clock-compensation.md).

Именованный аудиовыход выбирается по идентификатору `QAudioDevice`. При смене списка индекс пересчитывается. Если устройство исчезло, приложение сообщает об ошибке и сохраняет RX и запись. Пользователь может явно выбрать другой выход. Для режима «Системный выход» контроллер отслеживает изменение устройства по умолчанию.
