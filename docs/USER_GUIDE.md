# Руководство пользователя v0.1

## Приём

1. Установите модуль нужного устройства: соседние manifest JSON и DLL/SO в папку `devices` рядом с приложением. HackRF, RTL-SDR и Airspy поставляются отдельными модулями. Для них также нужны совместимый SoapySDR 0.8 runtime и внешний драйвер SoapyHackRF, SoapyRTLSDR или SoapyAirspy. Новый совместимый модуль другого семейства добавляется таким же способом, без пересборки приложения.
2. Подключите устройство и нажмите «Обновить устройства» при остановленном RX. Выберите источник, частоту в MHz, скорость IQ в samples/s и режим AM/NFM/WFM.
3. Нажмите «Начать приём». Spectrum показывает всю полосу источника; смещение задаёт частоту единственного VFO относительно центральной частоты.
4. Во время приёма измените параметры и нажмите «Применить». Перенастройка управляемо перезапускает тракт. Во время записи сначала завершите запись.

Неподдерживаемые PPM/Bias-T/direct sampling недоступны. Усиление находится в аппаратных пределах. Если драйвер изменил фактическую скорость/частоту, шкала спектра и статус используют фактические значения. При отсутствии runtime аппаратные источники недоступны; файл и синтетический генератор остаются доступны.

Папка `devices` может отсутствовать или содержать только нужные модули. Ошибка одного модуля не отключает исправные; подробности попадают в диагностику. Модули обнаруживаются при запуске и кнопкой «Обновить устройства» после остановки RX. Для удаления уберите manifest, обновите список и затем удалите библиотеку; для замены занятой DLL закройте приложение. Обновление во время RX отклоняется. Если сохранённый источник исчез, другой автоматически не выбирается. Старые аппаратные настройки мигрируют только при однозначном совпадении устройства.

«Synthetic / 1 kHz» создаёт контрольный AM/FM-сигнал внутри приложения. Это не радиоэфир. Он позволяет проверить отображение и демодуляцию без USB-устройства.

Реальные испытания RTL-SDR и Airspy перенесены после MVP v0.1; их адаптеры экспериментальны, совместимость на конкретном устройстве не подтверждена. Текущие обязательные аппаратные испытания относятся к HackRF One; короткий успешный RX не заменяет полную приёмку.

## Спектр и рабочее пространство

Колесо мыши меняет масштаб, перетаскивание сдвигает видимую полосу, щелчок задаёт смещение канала. «1:1» возвращает полную полосу. Верхний график — dBFS без калибровки dBm; waterfall хранит последние 256 спектральных строк, новые появляются сверху. При пропуске кадров история не является равномерной временной шкалой.

Панель управления можно переставить слева направо, изменить её ширину и переключать вкладки. В v0.1 нет плавающих окон и произвольного вложенного docking. Доступны тёмная/светлая/системная темы, три акцента, две waterfall-палитры и RU/EN.

Горячие клавиши: Space — запуск/остановка, Esc — остановка, Ctrl+O — открыть IQ. При редактировании текстового поля завершите ввод перед Space.

## Аудио

На вкладке «Аудио» выберите системное или конкретное устройство. Выход — mono float32, 48 kHz; несовместимый выход выдаёт ошибку. WFM пока mono с 75 μs deemphasis; стерео и RDS не входят в этот выпуск. Squelch и смена режима применяются кнопкой «Применить». Громкость меняется сразу.

Счётчик audio underrun отражает недостаток данных при чтении аудиобуфера; сообщение об ошибке аудиовыхода проверяется отдельно. Нулевой счётчик сам по себе не доказывает слышимость или допустимую задержку.

## Запись и IQ playback

Выберите существующую папку на вкладке «Файлы», включите WAV и/или Raw IQ и начните запись во время RX. Имена файлов уникальны; после штатного завершения WAV содержит корректный RIFF/PCM16 header, IQ — `.cf32` и `.cf32.json`.

Raw IQ содержит чередующиеся I/Q float32 little-endian до DDC. Sidecar описывает format/version/rate/center/capture point/time domain/sample count/discontinuities/complete. Он не является SigMF. Незавершённый sidecar остаётся `complete: false`; автоматическое восстановление повреждённых записей пока не выполняется.

Файловый источник принимает только CF32 little-endian. При наличии sidecar его параметры проверяются и используются. Без sidecar явно задайте частоту и sample rate перед запуском. Неизвестные версии, повреждённые metadata, NaN/Inf, неполный отсчёт и отмеченные разрывы не скрываются: воспроизведение отклоняется с диагностикой. EOF останавливает RX и освобождает источник. Перемотка/изменение скорости/циклическое воспроизведение отложены.

При заполнении диска запись завершается с ошибкой и не выдаётся за успешную. RIFF WAV ограничен 4 GiB. Для изменения rate, частоты или демодулятора завершите текущую запись и начните новый файл.

## Расширения

Остановите RX, нажмите «Добавить manifest…» и выберите JSON рядом с DLL/SO доверенного плагина. После проверки источник появится в списке источников, демодулятор — в списке режимов. Для отключения сначала остановите RX, затем нажмите «Отключить расширения».

Плагины работают внутри процесса. v0.1 не обеспечивает sandbox или сохранение GUI после аварии нативного расширения. Каталога и фоновой установки нет. Примеры и команды сборки — в Plugin SDK Guide.

## Настройки и диагностика

Настройки JSON v1 по умолчанию хранятся в локальном AppConfigLocation Qt. Файл `portable.txt` рядом с executable включает сохранение в соседний `sdr-settings.json`; каталог должен быть доступен для записи. Настройки сохраняются при закрытии окна. Повреждённый/неподдерживаемый JSON сохраняется без перезаписи, используется конфигурация по умолчанию; для восстановления исправьте или переименуйте этот файл вручную.

Журнал JSONL хранится в локальном AppLocalDataLocation и ограничен 4 MiB. Экспорт производится вручную через «Экспорт диагностики…». Журнал может содержать пути файлов и идентификаторы источника: просмотрите его перед самостоятельной отправкой. Автоматической телеметрии и отправки crash reports нет.

IQ overflow останавливает RX вместо неограниченного роста памяти. Уменьшите sample rate или нагрузку записи и повторите запуск. Сниженная частота спектральных кадров не означает сама по себе потерь IQ.
